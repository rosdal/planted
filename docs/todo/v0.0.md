# v0.0 development todo

Every step from an empty folder to a green first PR, in order. `planted` is the repo name, and the package scope is @planted/\*. The folder already exists; nothing else has run yet. Rough effort: one evening.

## 1. Before you start

Three decisions are hard to change after the first public push, so make them now.

**Decisions**
- [ ] Product name and package scope (`@planted/*` until then). Check the npm scope, GitHub org/repo and .gg/.app domain are free
- [ ] License: MIT (anyone can fork, even closed) or AGPL-3.0 (hosted forks must share changes; protects a free hosted service). Write the choice and the reason in ADR 0001
- [ ] Repo home: personal account or the Rosdal org

**Machine (WSL2)**
- [ ] Work inside the Linux filesystem (`~/code/planted`), not `/mnt/c`: file watching and installs are much faster
- [ ] Install fnm, then `fnm install --lts && fnm default lts-latest`; note the major version for `.nvmrc`
- [ ] `corepack enable` (ships with Node; pins pnpm per repo)
- [ ] Git identity: `git config --global user.name`, `user.email`, `init.defaultBranch main`, `pull.rebase true`
- [ ] Commit signing: SSH signing key added to GitHub, `gpg.format ssh`, `commit.gpgsign true`
- [ ] GitHub CLI: install `gh`, run `gh auth login`
- [ ] Docker Desktop with WSL2 integration (not needed until 0.1, but check it works now)
- [ ] VS Code with the WSL extension; open the folder with `code .` from WSL

## 4. TypeScript and Turborepo

Internal packages export their TypeScript source directly (no build step); only apps compile. This keeps the monorepo fast and avoids stale `dist/` bugs.
- [ ] `tsconfig.base.json` at the root:

```json
{
  "compilerOptions": {
    "target": "ES2023",
    "lib": ["ES2023"],
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "strict": true,
    "noUncheckedIndexedAccess": true,
    "exactOptionalPropertyTypes": true,
    "noImplicitOverride": true,
    "verbatimModuleSyntax": true,
    "isolatedModules": true,
    "resolveJsonModule": true,
    "skipLibCheck": true,
    "noEmit": true
  }
}
```

- [ ] Each workspace: `tsconfig.json` with `"extends": "../../tsconfig.base.json"` and `"include": ["src"]`; `apps/web` adds `"lib": ["ES2023", "DOM"]` and `"jsx": "react-jsx"`
- [ ] Internal packages point at source: `"exports": { ".": "./src/index.ts" }` in `packages/*/package.json`
- [ ] Each workspace script `"typecheck": "tsc --noEmit"`; stub apps get `"build": "tsc --noEmit"` for now (real builds arrive with Vite and the server bundler in 0.1)
- [ ] `turbo.json` (Turborepo 2 uses `tasks`):

```json
{
  "$schema": "https://turbo.build/schema.json",
  "tasks": {
    "build": { "dependsOn": ["^build"], "outputs": ["dist/**"] },
    "typecheck": { "dependsOn": ["^typecheck"] },
    "dev": { "cache": false, "persistent": true }
  }
}
```

- [ ] Add `.turbo` to `.gitignore` (done in step 2) and run `pnpm typecheck` twice: the second run should hit the cache (`FULL TURBO`)

- [ ] `commitlint.config.js` extending `@commitlint/config-conventional`

**CI workflow** `.github/workflows/ci.yml` (use the latest major of each action):

```yaml
name: ci
on:
  pull_request:
  push:
    branches: [main]
concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true
jobs:
  ci:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version-file: .nvmrc
          cache: pnpm
      - uses: actions/cache@v4
        with:
          path: .turbo
          key: turbo-${{ runner.os }}-${{ github.sha }}
          restore-keys: turbo-${{ runner.os }}-
      - run: pnpm install --frozen-lockfile
      - run: pnpm check
```

## 8. Done check

v0.0 is finished when all of these pass, in this order, on a clean machine state.
1. `cd /tmp && git clone <repo> planted-check && cd planted-check`
2. `fnm use && corepack enable && pnpm install --frozen-lockfile` finishes with no warnings about peer deps or engines
3. `pnpm check` exits 0 (lint, typecheck, build, test)
4. `pnpm typecheck` a second time prints `FULL TURBO`
5. Break something on purpose (an unused import), commit: the hook fixes or blocks it
6. Commit with message `wip`: commitlint rejects it
7. Push a branch, open a PR: CI runs and goes green in under 2 minutes; merging without green CI is blocked
8. Merge the PR (squash); tag `v0.0.0` on `main` and push the tag
